# 泌尿科 AI 實戰：示範資料與交辦句

2026-11-12 慈濟跨院區泌尿臨床個案討論會 Special lecture「泌尿科醫師的 AI 實戰」現場示範用的檔案。

> ⚠️ **全部是亂數產生的假資料，不是任何病人。** 真的病人資料不要上傳到網頁版 AI。

## 檔案

| 檔案 | 是什麼 |
|---|---|
| [`假資料-結石處置-髒.xlsx`](假資料-結石處置-髒.xlsx) | 120 筆結石處置假資料，**故意做亂**：欄名中英混用、大小單位不一（12mm／1.2cm／約1公分）、民國西元混用、合併儲存格、備註寫在數字格、重複病人、打錯值，右邊還有一張對不上的月統計小表和圖 |
| [`make_messy_stones.py`](make_messy_stones.py) | 產生上面那份檔案的程式（固定 seed，重跑結果一樣）：`pip install openpyxl` 後 `python make_messy_stones.py` |

點進 xlsx 後按右上角的下載鈕（Download raw file）即可下載。

## 怎麼練

1. 打開 Claude（或 ChatGPT、Gemini）網頁版，開新對話，上傳 `假資料-結石處置-髒.xlsx`。
2. 依序貼下面的交辦句。〔〕裡的字換成你自己的。

### 幕一：先叫它盤點，不要分析

```
這是一份假資料。先不要分析，請告訴我：① 這張工作表裡有幾張表、各是什麼；② 哪裡亂（格式、單位、重複、明顯打錯），你打算怎麼清；③ 這份資料能回答哪些臨床問題。清資料的每個決定，先列出來讓我確認。
```

### 幕二：問它最有故事的地方

```
目標是把這份資料寫成一篇投〔目標期刊〕的論文。頂尖的泌尿科研究者拿到這份資料，會做哪些我沒想到的事？這份資料最有故事的地方是什麼？先給我研究計畫：研究問題、主要結果、統計方法、為什麼選這個方法、還有哪些替代方法、怎麼證明結論站得住。等我說開始再跑。
```

> 這句刻意不寫「你是頂尖研究者」：角色扮演通常只讓措辭變華麗；問「頂尖的人會做哪些我沒想到的事、怎麼證明」，它才會把專家的做法搬出來。

### 數字可以信，決定要檢查

```
把你清資料時做的每個決定列成表：改了什麼、刪了哪幾列、為什麼。再說明為什麼選這個統計方法，還有哪些替代方法、各自的前提。
```

### 請它換領域，看同一個問題

```
先別用泌尿科的角度。我真正要做到的是：〔讓結石病人在沒症狀的幾年裡，還願意多喝水、定期回來追蹤〕。哪些行業最擅長做到這件事？挑三個，說它們怎麼做，哪一招可以借來用在我們門診。
```

### 搜完文獻，叫它自己驗兩關

先在設定的 Connectors 打開 PubMed，問完臨床問題、它給了引用之後貼：

```
逐條檢查你剛才的引用：① 用 PubMed 確認這篇存在，作者、年份、標題都對；② 從摘要或全文找出支持那句話的原文，貼出來。找不到就標「不支持」，不要自己補。
```
